4 Skills every web developer needs

  • Responsive design
  • Version Control
  • Backend Systems and API's

3 HTML Terms

Tags
Tags are keywords wrapped in brackets that tells a web browser how to display content.
Attributes
Attributes are keywords placed in an opening tag that manipulate how the content is displayed.
Hyperlinks
Hyperlinks are clickable text that connect the current webpage to another page, file, or external website, these are created using the anchor tag and href attribute to redirect the user to the target page/website.
