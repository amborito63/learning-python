Steps to create a simple website

  1. Define the Purpose of the Website
  2. Choose the platform of the website
  3. Secure a domain name
  4. Build and Design the webpages
  5. Test, Debug, then Publish the website

4 Skills every web developer needs

  • Proficiency in HTML, CSS, and Java
  • Responsive design
  • Version Control
  • Backend Systems and API's

3 Semantic Tags + Descriptions

STRONG Tag
The strong semantic tag gives emphasis to a specific word or sentence, which signifies importance.
HEADER Tag
The header tag acts as a container for introductory terms in a website.
NAV Tag
The nav tag allows the user to add a navigation menu, with internal links in the website.
